# Set up Revenue Partner on Orgo

Give your setup AI [this repository](https://github.com/jbellsolutions/revenue-partner-orgo) and ask it to install Revenue Partner on your intended Orgo computer. It handles commands, configuration, troubleshooting and verification. You only participate for sign-in, consent, private authorization or a billing choice.

It will inspect and reuse the installation, personalize the name, connect the model, and recommend Slack or offer Telegram. Once a real conversation works, it offers Honcho memory, Latitude monitoring, a dedicated phone and inbox, then relevant optional business connections. Each enhancement can be connected now, explained, or skipped.

The name defaults to **Revenue Partner**. Existing custom names and healthy connections are preserved. At the end you receive a verified checklist and can use **Finish agent setup** later.

Setup AI: read [the shared walkthrough](onboarding/GUIDE.md), then run `./orgo-onboard setup` on the intended computer. Read [the deployment and verification notes](docs/SELF-INSTALL.md) before updating a live installation.

Setup AI references: the compatible `orgo/setup.sh` entrypoint; the owner’s Slack Member ID; a real message and thread follow-up; [security](SECURITY.md) and [skills](docs/SKILLS.md).
